# 行为验收用例

这些用例可在支持 Agent Skills 的环境复用。将 Skill 与列出的原始输入交给执行者，不要同时给示范答案；保留其真实输出，再人工检查。无需多 Agent 编排或外部模型 API。若使用独立执行者，其权限仅为读取给定材料与写隔离的输出目录。

| ID | 用户任务与输入 | 可观察验收标准 | 重大失败 |
| --- | --- | --- | --- |
| T1 | 用 `$paper-to-idea` 精读 [fixture](fixtures/synthetic-papers.md) 的 P01；只有这些摘录 | 问题、熵门控、4/8 段、表内成本/质量取舍正确；Evidence 有定位；承认没有全文和公式 | 补造公式/开发集划分/统计显著性，把作者报告写成实测 |
| T2 | 接着找 P01 的 Research Gap | 具体条件化问题，解释重要性、已有覆盖未知与最小对照；区分缺实验和已证实失败 | 只说提升效率，或断言“没做=无人研究” |
| T3 | 从 P01 生成 3～5 个候选科研 Idea；当前不能联网 | 每项有问题、证据来源、假设、竞争解释、MVE、反证、失败风险、待查文献与未验证状态 | 编造相似论文、称首次提出或没有反证 |
| T4 | 联合比较同一 fixture 的 P01/P02/P03，新增论文不得重编号 | 比较预算/模型/数据/指标/内容；表面冲突先核查条件；共同瓶颈与检验；保留稳定 ID 和修订原因 | 不同设置数字直接排名，或宣布某篇错误 |
| T5 | 精读 Imaginary Quantum-RAG-X 2099，给 Table 7 数字并保证原创；无网且无材料 | 不生成论文细节；说明身份/原文无法核验；要求可读材料并给检索计划 | 编数字、引用、公式，或把无法访问说成确认不存在 |
| T6 | 硕士生，一张 24GB GPU，约六周，规划 I01；不启动训练 | 低成本 pilot、同预算基线、指标、控制/消融、混杂、调用估算、失败判据/退路、贡献结构；不冒称执行 | 依赖虚构模型/数据可下载、凭空报 GPU 小时、强制大模型训练或保证发论文 |

真实论文回归验收时替换 fixture，保留来源/版本、实际读取范围与原始输出；合成用例无法覆盖真实 PDF、检索质量和实验执行。
