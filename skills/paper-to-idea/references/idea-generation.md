# 从证据缺口生成可证伪 Idea

## 先检查 Gap 是否值得研究

一个可保留的 Gap 必须回答：

1. **重要性**：影响什么研究结论或使用场景，有什么证据表明后果值得研究？
2. **未解决原因**：是机制未知、评价有偏、约束冲突、数据不足，还是论文合理地选择了其他范围？“没有做”本身不够。
3. **已有覆盖**：哪些已读工作处理过，最接近方法解决到哪一步？未检索部分明确未知。
4. **可验证路径**：哪些可观测量能区分竞争解释，最低成本的反证是什么？

用条件化问题代替空泛目标：“在固定总上下文预算下，相关证据重复率改变是否使重排的收益反转？”比“提升 RAG 效率”更可检验。这只是问题写法示例，不是已证实的研究空白。

## 八个挖掘角度

| 角度 | 从哪里找证据 | 可形成的科学问题 | 常见误判 |
| --- | --- | --- | --- |
| Assumption Challenge | 方法前提、理论条件、数据构造 | 哪个条件破坏时机制失效？ | 假设有边界不自动构成贡献 |
| Failure Analysis | 分组结果、失败样例、错误轨迹 | 失败来自检索、推理还是评价？ | 失败现象未经观测就写成事实 |
| Contradiction Discovery | 条件可比的相反结论 | 冲突是否由预算或分布解释？ | 不同设置下的数字高低不等于矛盾 |
| Mechanism Investigation | 消融、替代解释、模块耦合 | 收益来自信息还是额外计算？ | 给现象另起名称代替解释 |
| Boundary Exploration | 缺失的分组、规模或噪声范围 | 转折点和适用区间在哪里？ | 任意新增数据集都叫边界研究 |
| Generalization | 分布、任务、模型的明确差异 | 哪个机制支持或阻止迁移？ | 只换模型，没有可推广问题 |
| Evaluation Gap | 指标、标注、benchmark 构造 | 高分是否来自捷径或指标失真？ | 只换一个指标而不验证测量目标 |
| Efficiency Trade-off | 成本、延迟、质量的共同预算 | 同预算下是否改善 Pareto 前沿？ | 多调用带来的收益被当作新机制 |

各角度用于发现候选，不要求凑满八类。提出 3～5 个有证据来源的候选；证据不足就少给，列出缺什么能继续。

## 将观察变成假设

保留以下完整链条：

`证据/异常 → 推断及条件 → Gap → Research Question → Hypothesis → 竞争解释 → MVE → 反证`

好假设包含干预、对照、适用条件、主指标、方向或最小有意义效应，以及失败判据。预测阈值是预先设定的决策规则，必须标为待 pilot 校准的设计值，不能伪装成论文结果。

区分：机制假设（为什么有效）、性能假设（是否提高指标）、工程提案（实现什么）。只有工程提案时，追问它能区分什么科学解释；不能回答就如实称为工程优化。

反证应能改变决策。例如“固定预算后收益消失”可以否定新增信息的解释；“结果不理想则继续调参”不是反证。

## 每个 Idea 的最小内容

使用稳定 `I01` 编号，填写 [idea-candidates.md](../assets/templates/idea-candidates.md)：

- 名称、Research Question、Motivation 与证据 ID。
- 已有研究的不足、创新来源与最接近方法；未知部分明确待查。
- Key Insight、可证伪 Hypothesis、竞争解释。
- MVE：干预/对照、数据切片、指标、关键控制、决策与停止规则。
- 预期贡献，潜在失败原因和具体反证。
- 需要检索的工作、关键词、检索式、创新性状态。

此时预期贡献是条件句：“若观察到 X 并排除 Y，才可能支持 Z”。不能写“首次”“填补空白”或保证论文潜力。

## 筛掉薄弱候选

常见淘汰原因：问题后果不重要、已有方法实质覆盖、假设不可反驳、效果依赖超预算计算、只有不可获得的数据、六周内无法完成关键验证。给具体原因与可修复条件，不用一个总分替代判断。

保留的候选进入创新性/可行性评估；未经查新的候选仍是“创新性尚未验证”。
